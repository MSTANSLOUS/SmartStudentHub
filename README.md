# 🎓 Student Portal System

A user-friendly web-based system that allows students to register, log in, and access a personalized dashboard for managing courses, assignments, grades, and other academic resources.

---

## 📌 Features

- 🔐 **User Authentication**
  - Secure sign-up and login functionality using PHP and MySQL
  - Session-based access control

- 🧾 **Student Dashboard**
  - Personalized welcome message
  - Navigation to sections like:
    - My Courses
    - Grades
    - Assignments
    - Settings

- 🔔 **Notifications**
  - Notification bell icon with badge for reminders (e.g., deadlines, messages)

- 📅 **Upcoming Deadlines**
  - Section showing upcoming academic activities such as projects or tests

- 🎨 **Beautiful UI**
  - Stylish frontend built with HTML5, CSS3, and Google Fonts
  - Responsive and clean interface
  - Animated transitions and a preloader using SweetAlert2

---

## 💻 Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 / CSS3 | Markup and styling |
| PHP         | Backend server-side scripting |
| MySQL       | Database for user and academic data |
| JavaScript  | Client-side interactivity |
| SweetAlert2 | Loading/preloader UI |
| Font Awesome| Icons (e.g., bell icon for notifications) |
